# 🎨 SillyTavern ComfyUI Illustrator (酒馆伴读插画插件)

基于 SillyTavern (酒馆) 的 ComfyUI 原生前端扩展插件。  
自动识别聊天文本中的插画标记标签，调用本地 ComfyUI API 在后台自动生图并嵌入界面，支持**可自由拉伸缩放、自由拖拽移动的左侧独立伴读画廊**。

---

## ✨ 核心特性

- **🖼️ 独立伴读画廊视窗（核心推荐）**：
  - 脱离消息气泡裁切限制，在界面左侧拥有独立大图展示区。
  - **长文伴读不滚屏**：即使单条回复长达数千字，左侧插图始终固定悬停在视线前方，无需下拉滚轮即可直接欣赏。
- **🎯 自由交互与位置记忆**：
  - **自由拖拽**：按住标题栏可随意拖动到屏幕任意位置。
  - **自由拉伸**：拖拽右下角手柄任意调整视窗长宽，内部图片自动保持比例缩放变大，绝不变形。
  - **自动持久化**：视窗位置、视窗尺寸、悬浮球位置刷新网页自动记忆，并提供 **一键 🔄 复位** 功能。
- **🔄 多种渲染位置**：
  - 支持 `左侧独立伴读视窗`、`消息最底部`、`消息最顶部`、`正文标签原位` 自由切换。

## 📦 安装方式

### 方式一：酒馆界面在线安装（推荐）
1. 打开 SillyTavern，点击顶部工具栏的 **🧩（扩展管理/积木图标）**。
2. 点击 **【安装扩展（Install Extension）】**。
3. 粘贴本仓库的 GitHub 链接，点击确认，酒馆会自动下载并激活。
4. 按 `Ctrl + F5` 刷新网页即可看到右下角调色盘悬浮球 🎨。

### 方式二：手动文件安装
1. 克隆或下载本仓库压缩包。
2. 将文件解压至酒馆目录：`SillyTavern/public/scripts/extensions/third-party/comfyui-illustrator/`。
   *(确保 `manifest.json` 和 `index.js` 直接在 `comfyui-illustrator` 目录下，不要多层嵌套)*
3. 重启酒馆后端服务，刷新网页。

## ⚠️ 关键前置配置：ComfyUI 设置（必看）

由于浏览器沙盒安全策略，酒馆前端直连本地 ComfyUI **必须开启跨域（CORS）**。

### 1. 开启 ComfyUI 跨域启动参数

启动 ComfyUI 时必须附带参数：`--enable-cors-header *`

---

### 2. 导出 API 格式工作流（重点避坑）

> ⚠️ **严正注意**：不可直接使用 ComfyUI 顶部的普通「Save/保存」，必须导出为 **API 格式**！

1. 打开 ComfyUI 网页界面，点击右上角的 **⚙️（设置/Settings）**。
2. 勾选 **`Enable Dev mode Options`（启用开发者模式选项）**。
3. 此时控制区会新增一个按钮：**`Save (API format)`（保存为API格式）**。
4. 点击该按钮，下载 `.json` 格式的工作流文件。
5. 用记事本打开下载的 JSON 文件进行修改：
   * **正向提示词节点**：找到正向 Prompt 文本输入框的内容，替换为占位符：`%prompt%` *(必需)*
   * **随机种子**：找到 KSampler 节点的 seed，替换为：`%seed%` *(可选，推荐)*
6. 复制整段 JSON 内容，粘贴至本插件的「工作流」设置输入框中。

## 📝 引导 AI 角色生成插画标签

在你的角色卡设定、系统提示词（System Prompt）或作者注释（Author's Note）中加入以下指令，引导 AI 在合适的情境下输出标签：

> **提示词规则建议（复制至系统提示词）：**
> ```text
> [在剧情推进到重要场景、情绪高潮时刻或出现具有强画面感的情节时，请在回复末尾额外输出一个画图提示词。必须使用以下严格格式：
> image### (masterpiece, best quality, 画面描述标签, 外貌特征, 场景细节) ###
> 提示词必须全部使用英文 Tag 形式，不要包含中文，标签之间用逗号隔开。]
> ```

## ❓ 常见问题排查（FAQ）

#### Q1：点击插件中的【测试连接】按钮报红、提示失败？
1. 检查 ComfyUI 是否已经在后台启动，且网页能正常访问。
2. 确认 ComfyUI 是否添加了 `--enable-cors-header *` 参数并重启。
3. 检查控制台（F12），若看到红字 `CORS policy blocked`，证明跨域未成功生效。
4. 确认端口是否匹配（默认 8188，改过端口请填写对应端口）。

#### Q2：点击【开始生成】后立即提示生成失败？
1. 检查填入的工作流中是否包含了 `%prompt%` 占位符。
2. 确认粘贴的 JSON 是否为 **Save (API format)** 导出的 API 格式，而非普通工作流 JSON。

#### Q3：左侧画廊视窗移出屏幕外/找不到了怎么办？
点击画廊顶部的 **🔄（复位按钮）**，窗口会立即恢复到默认位置和初始尺寸。

#### Q4：移动端或小屏幕电脑显示效果？
插件内置了媒体查询响应式支持。当屏幕宽度小于 1250px 时，左侧大图视窗会自动停用，建议在设置中切换为“消息最底部”模式。
